# NeoBee 品牌与视觉系统

这份文档记录已确认的公共身份和网站呈现规则，供以后增加作品、改文案、修布局时使用。它不把所有页面冻结成同一张截图；它要求每次变化仍能看出同一个 NeoBee。

维护基准建立于 **2026-09-11**，视觉参照为已验收提交 **`4cff5da`**。本文结合当前代码和后续对话决定；早期重构 brief 中的建议若与此不同，以较新的确认结果为准。

关键原则的来源类型、适用范围和禁止外推见[决策记录](decision-register.md)。历史档案中的综合定位是理解背景的材料，不是新 slogan，也不自动授权替换官网文案。

## 1. 对外身份与命名

The NeoBee Club 是立足都柏林、**以音乐为主导的跨文化创意团体**。音乐带动影像、空间、现场与其他媒介的实践，不是多个服务类别中随意并列的一项。入口仍然是 **Sound. Space. Culture.／声音。空间。文化。**；作品、具体空间和人的参与让这句话成立。餐厅、快闪、某种设备或视觉实验不能代替整体定位。（B01）

都柏林是起点和真实发生地，不是地域上限。云南、中国、亚洲及其他文化经验可以成为具体作品的声音与视角，不必将每次实践包装成地域宣传，也不据此限定整个品牌的受众。跨文化通过真实内容和参与关系表达，不靠身份标签代替作品说明。（B02）

| 使用位置 | 写法与分工 |
| --- | --- |
| 网站总称、组织介绍、搜索信息 | **The NeoBee Club** |
| 音乐与现场分支 | **NeoBee Club**：Sessions、现场体验、合作与实验 |
| 视觉分支 | **NeoBee Studio**：摄影、动态影像、现场记录与视觉方向 |
| 成员 | **Hao** 与 **Leo**，保留已确认的照片、简洁介绍及个人社媒 |
| 实验项目 | **Ghostframe**，介绍为视觉实验，放在实验语境中 |

两个分支并列时名称结构一致。不要全局删除所有 “The”，也不要让 Studio 的服务介绍变成整个网站的语气。Hao 与 Leo 的存在提供真实的人物背景，人物照片可以承担分支入口的主视觉。

团体作品以 NeoBee 的呈现品牌和作品为主层级，准确保留艺人、演奏者与制作署名。Hao 的人物介绍和 HAØSC／HAOSC 的作品署名按语境使用，个人频道与品牌频道分开；品牌优先不意味着删除个人社媒或弱化真实贡献。当前人物分工不限定其全部创作能力。（B05）

## 2. 整体气质如何落实

网站接近独立音乐出版物和当代文化档案：安静、自信、有选择，也容易进入。气质来自具体处理，而不是在文案里宣称“高级”。

这里的“安静”描述页面呈现，不是音乐类型限制。音乐方向保持 genre-fluid；YiBU 等具体场景的音量、强度和选曲要求仅用于相应场景，不能外推为全品牌禁止 techno、实验或更强烈的作品。判断新内容时看实际音乐、作品质量与现场条件，不要求它复制上一场的声音。（B04）

| 原则 | 页面上的表现 | 检查时关注 |
| --- | --- | --- |
| 让作品成为重点 | 真实场地影像足够大，标题、播放入口、场次信息层级清楚 | 第一眼是否能找到作品与播放入口 |
| 编辑感 | 强标题、细分隔线、小号索引、有限的非对称构图 | 是否出现很多相同卡片、同等强度的大标题或互抢注意力的按钮 |
| 留白有结构 | 标题、正文、图片信息形成组，章节之间有明显停顿 | 是否把相邻容器的上下间距累加成空洞；组内是否又过密 |
| 有温度 | 纸色背景、墨黑文字、真实光线与材质 | 是否用过度锐化、统一滤镜或无关装饰抹掉场地特点 |
| 克制的个性 | 主视觉允许实验，其余阅读和导航稳定 | 是否把每段文字都做成特效，或用新装饰填满空白 |
| 文化表达具体 | 说明这次用了什么声音、在哪里、由谁完成 | 是否只剩抽象的“连接、融合、赋能、沉浸”等词 |

默认不添加夜店霓虹、渐变光球、玻璃卡片、蜂巢图案、夸张阴影、无限滚动字带或整页滚动劫持。一个新效果需要说明它如何服务具体作品和阅读过程。

纸色、墨黑与编辑式排版是当前获确认的视觉基准，不是永恒不变的品牌定义。日常更新继续沿用；新的视觉方向经用户确认后，连同理由与参照更新，不从更早的视觉提案中自行拼接一套新系统。（V01）

## 3. 字体分工与当前参数

字体定义在 `src/app/[locale]/layout.tsx`，排版在 `src/app/globals.css` 与主视觉 CSS module。加载字重与实际使用字重不同，不要因为字体加载了某个字重就全站使用它。

| 字体 | 已加载字重 | 当前角色 |
| --- | --- | --- |
| **Playfair Display** | 600／700／800 | 英文展示标题。桌面普通标题以 700 为主；多个手机长标题降为 600；主视觉英文扫描字为 800 |
| **Montserrat** | 400／500／600／700 | 英文正文与辅助信息。正文通常 400；导航、索引、按钮和短元信息常用 700，局部用 500／600 |
| **Noto Sans SC** | 400／500／700 | 中文正文与标题。正文通常 400；中文展示标题和主视觉为 700 |

当前正文基准为 **16px、行高 1.6**。普通英文标题基准为 **700、字距 -0.035em、行高 1.02**；中文基准为 **字距 -0.04em、行高 1.1**。具体组件有覆盖：多个手机长标题使用约 **600、-0.025em、1.06–1.10**，对应中文使用 **700、-0.025em、1.13**。不要用全局基准覆盖这些已经为长文案放松过的规则。

Hero 的紧字距和较紧行高属于三行单词扫描构图，只适用于该区域。它们不适合复制到长标题或正文。增加字号不能代替层级设计。

### 长标题与双语断行

- 英文保留 Playfair 的性格，但长标题要给上下伸部足够空间。遇到“像大字报、字挤在一起”的反馈，先看字号、行高、字距和可用行宽，而非立即换字体。
- 中文按短句阅读。已确认的 YiBU 首页标题为两行：**录于白昼，／献给入夜之后。**。“录于白昼”不能被拆成“录于白／昼”。
- 新标题不能盲目继承当前短句的 `nowrap`。短句更长时，应缩短文案、重新安排短句或调整局部字号，并检查 320px，而不是裁切溢出。
- 中英文可以使用不同字号和行数，需保持相近的层级与呼吸感。事实一致不等于逐字翻译或相同断行。
- 句号与文字的视觉间隔要一致，尤其是“声音。空间。文化。”三个词。检查时比较完整三行，不能只看其中一行。

## 4. 色彩与边界

| Token | 当前值 | 用途 |
| --- | --- | --- |
| `--ink` | `#11110f` | 主文字、深色章节 |
| `--paper` | `#efe9dc` | 主纸色背景 |
| `--paper-deep` | `#e4ddcf` | 次级纸色层次 |
| `--white` | `#faf7ef` | 深底文字与偏暖浅色 |
| `--accent` | `#d85735` | 陶土橙强调、选中状态、部分联系区域 |
| `--signal` | `#f1bd32` | 播放提示、焦点等小面积高辨识元素 |
| `--line` | `rgba(17,17,15,0.24)` | 浅底细分隔线 |
| `--line-light` | `rgba(250,247,239,0.24)` | 深底细分隔线 |

纸色和墨黑承载大部分页面；橙与黄有明确用途。图片自身可以带来丰富颜色，不需要为每个新项目再加一组品牌色。黄色播放入口是现有界面的一部分，不发展成蜜蜂主题装饰。

## 5. 构图、留白与页面长度

普通页面容器上限为 **1440px**；桌面通常保留左右各 **20px**，760px 及以下通常为 **14px**。章节基准留白为 `clamp(80px, 8vw, 128px)`，手机为 **68px**。这些是理解现有节奏的参考，不要求每个区块拥有同一高度。

首页 Featured 桌面为左图右文，文字栏带 **36–64px** 的顶部光学偏移；1040px 及以下转为单栏、文字在上。文字栏最小宽度为 **380px**，在刚进入双栏时也能容纳当前中文短句；这不是给未来更长文案无限使用 `nowrap` 的许可。图片区与场次元信息之间为 **16px**。标题与正文保持约 **22–32px**。不要改回文字贴图片底部的低重心布局。

Featured 和 Selected Sessions 之间已经处理过重复留白。检查应看两个内容块之间的实际距离，而不只是单个 `margin`。一屏内既要有停顿，也要能看出下一段的关联。

首页承担选择：一个主推 Session，加少量精选；完整历史记录进入 Archive。新增作品要明确它替换哪个精选位。作品增加不应使首页无限变长。Studio 的选择依据视觉表达与相关性，不能只因有一个新视频就重复堆叠几张相近画面。

保留主导航与首页章节目录的分工。手机目录展开后应能快速抵达目标，并在选择后收起；章节标题不能被固定目录遮挡。新分类需要真实内容支撑。

## 6. 图片与素材方向

优先使用现场的人、乐器、设备、空间细节、光线和互动。图片需要让观众理解作品发生在哪里。可以有运动模糊、颗粒与自然的不完美，但主体和使用目的应清楚。

- 新素材先检查原图，再检查最终裁切。人脸、演奏动作、仪器、场地标识或封面文字不能被无意切掉。
- 16:9 视频封面保留作品辨识度；竖幅素材按版面另选裁切。不要把一张不适配的封面拉伸填满。
- 优先保存经过优化的本地图片。核实来源、使用范围和替代文本；不要依赖临时外链或受登录限制的图片。
- 已有素材足够就复用。生成图不能冒充真实活动、真实观众或真实场地记录。
- 不为“丰富页面”重复放同一张强视觉；同一个素材再次出现要有不同的信息用途。

## 7. 双语文案与事实边界

标题可以略带诗意，紧接着的介绍应让人知道实际内容。中文保留氛围，同时像一个人说话；英文简洁自然，避免机构介绍式空话。音乐类型、作品名、艺名可以保留原文，不必强行汉化。

| 场景 | 合适的表达 | 应避免的写法 |
| --- | --- | --- |
| YiBU 标题 | “录于白昼，献给入夜之后。” | “跨越时空的多维沉浸式声音盛宴” |
| YiBU 介绍 | 交代 HAOSC、YiBU、现场 DJ Set 与音乐范围 | 只有“声音与空间的深度连接”，不说发生了什么 |
| 联系入口 | “想合作吗？”／“和我们一起做点什么。” | “告诉我们，你正在做什么。”这类脱离合作语境的直译 |
| 英文介绍 | “Recorded in daylight at YiBU, imagined for after dark.” 后跟具体音乐范围 | “Where creativity meets innovation” 等可以放在任何品牌的句子 |
| 成员介绍 | 当前工作与已确认作品、个人社媒 | “刚开始尝试”“积累经验中”等削弱表达的自我评价 |

专业表达依靠作品和准确职责，不靠自谦，也不靠夸大。已完成作品、可承接方向和长期愿景分别陈述；Studio 的服务入口或完整视觉系统不证明团队规模、稳定客户、收入或已达成合作。任何这类声明都需要独立、可公开的依据，不以私人沟通填充公共品牌叙事。（B03）

首页 Featured 只出现一套标题与简介，中英文、桌面与手机都一样。Club 和 Archive 的独立卡片需要完整信息，不能为修首页重复而全局删除。

已确认事实：YiBU 是餐厅中的 Session 录制；云南菜单发布由 NeoBee 带来云南主题 SP-404 Set。Kawa 是其中的歌曲来源，不能写成 Kawa Band 当晚现场演出。保留历史活动链接原本的 URL；链接路径文字不能推翻用户确认的实际内容。

发布与录制日期须各有来源。日期差异可能来自来源时区，但不能未经核实就认定是时区所致，也不能仅凭先后顺序擅自“纠正”。未知时长、参与者、地点、合作关系和未来活动不靠推测补齐；公开视频或新系列标签不自动获得 Session 编号。

公共网站与维护记录只保留完成本次更新所需的已公开或获准公开事实。未经公开的商业安排、策略、私人沟通和账号凭证不进入页面、版本化文档、截图附件或结构化数据。

## 8. 动效与可访问性

主视觉的特征是双语扫描：所选语言为主文字，扫描层出现对应翻译。三个词都要有翻译，交互之后仍能读懂标题。

- 桌面扫描跟随指针，停在最后位置；支持拖动，点击进行双向扫描后回到原位置。
- 手机轻触触发扫描，手柄支持水平拖动；在手柄以外应能自然上下滚动页面。
- 首次进入在当前浏览器会话中自动示范一次。用户交互优先，不反复打断阅读。
- 尊重 `prefers-reduced-motion`，保留可理解的静态信息；键盘可以聚焦并触发，焦点可见，辅助技术能读到完整标题。
- 导航、按钮、图片的反馈保持短、轻、可预测。当前普通反馈多在约 180–500ms；主视觉约 1–2 秒的扫描是局部例外。
- 不自动播放声音，不默认加载沉重视频，不为动效拖慢阅读与点击。新增效果需要在真实手机上感受滚动与触摸。

## 9. 如何判断仍然符合方向

自动检查能抓部分重复、缺失、链接格式、文字越界和交互问题；它不证明外链可播放，也不能判断氛围、构图或措辞是否成立。不要用自动“品牌分数”代替审阅。

审阅时至少留下三条具体观察：**视觉重点在哪里、阅读节奏怎样、这次内容为什么适合当前呈现**。例如：“新封面文字很大，因此右栏标题保持两行、减轻元信息，不再增加第二个徽标。”比“看起来更高级”更可复用。

样式或品牌变化需要保存同视口前后图、写明改变与理由。用户确认新的方向后，再更新本文和对应检查基线。以当前用户需求为准，不把规范变成阻止合理演进的审批流程。
